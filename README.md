# مساعد التوظيف الذكي — AI Job Hunter 🇪🇬

منصة عربية (RTL) متكاملة للبحث عن الوظائف في **مصر**، تعمل كتطبيق ويب ثابت (Static SPA) بالكامل — بدون أي خادم خلفي. تجمع بين البحث الحقيقي في الويب (Serper)، التحليل بالذكاء الاصطناعي (Gemini)، اكتشاف الشركات وجهات HR والإيميلات الموثقة (Hunter.io)، الإرسال الجماعي الذكي (EmailJS)، وقاعدة بيانات دائمة عبر RESTful Table API.

---

## 🎯 الهدف

أتمتة دورة البحث عن عمل كاملة: **اكتشاف الوظائف ← التطابق الذكي ← تخصيص الـ CV ← اكتشاف الشركة وجهات HR ← إيجاد إيميل موثّق ← توليد رسالة مخصصة ← مراجعة واعتماد ← إرسال ← تتبع عبر Kanban ← متابعة ذكية** — كل ذلك ببيانات حقيقية فقط، **بدون أي بيانات وهمية أو مولّدة**.

---

## ✅ الميزات المكتملة

### 1) وكيل الصيد الوظيفي (AI Job Hunter Agent)
- خط أنابيب كامل: بحث → جمع → إزالة تكرار → تحقق → تطابق → اكتشاف شركة → دومين → HR → إيميل موثّق → ترتيب → تجهيز.
- **مراجعة واعتماد إلزامية** قبل أي إرسال (Review & Approve).
- معايير: المسمى المستهدف، المدينة، سنوات الخبرة، عن بُعد، الحد الأدنى للراتب، المجالات، حد التطابق الأدنى.
- إلغاء قابل للتنفيذ في أي لحظة + إرسال النتائج المعتمدة للحملة الذكية.

### 2) البحث الحقيقي في الويب — Serper فقط
- `POST https://google.serper.dev/search` بمفتاح `X-API-KEY` ومعاملات `{q, gl:'eg', hl:'ar', num}`.
- مصادر: LinkedIn Jobs، Wuzzuf، Forasna، مواقع الشركات، وأي Job Board — كلها **نتائج حقيقية 100%**.
- دعم تكميلي اختياري: JSearch (RapidAPI) بفلتر `country=eg`.
- **Google Custom Search / API Key / CX أُزيلت نهائيًا** وممنوعة في الكود.

### 3) التطابق الذكي (Smart Job Matching)
- درجة تطابق % لكل وظيفة مقابل الـ CV النشط عبر Gemini (JSON mode).
- تفصيل مركّب: المهارات، الخبرة، المسمى، الموقع، المجال، التعليم + كلمات مطابقة/مفقودة.
- ترتيب النتائج حسب الدرجة + شارات (عالٍ ≥75 / متوسط ≥50 / منخفض).

### 4) ذكاء الشركات + قاعدة الشركات
- إثراء تلقائي لكل شركة: الموقع الرسمي، الدومين، LinkedIn، صفحة الوظائف، صفحة التواصل، المجال، المدينة.
- صفحة **قاعدة الشركات**: بحث/فلترة/ترتيب (آخر تحقق، الاسم، المجال، الدومين) + تعديل + حذف + تحديث + تصدير CSV (BOM للعربية) + ملف شركة كامل.
- **ملف الشركة**: بياناتها، وظائفها، جهات HR، الإيميلات، طلبات التقديم، وخط زمني للتواصلات.

### 5) اكتشاف جهات HR/التوظيف
- 7 استعلامات Serper (إنجليزي + عربي) لكل شركة.
- **أشخاص حقيقيون فقط** من روابط `linkedin.com/in/` الفعلية — لا يُولَّد أي رابط LinkedIn مُخمَّن.

### 6) خط أنابيب الإيميلات + نظام الحالات
- الترتيب: **Hunter.io → Serper (نصوص النتائج) → موقع الشركة** — بلا أي تخمين.
- حالات الإيميل: `Verified` / `Found` / `Unverified` / `Invalid` / `Guessed`.
- **الإرسال مسموح فقط لـ Verified و Found** — Guessed لا يُرسَل إليه أبدًا ولا يظهر كهدف.

### 7) قاعدة بيانات دائمة + Smart Cache
- 10 جداول عبر Table API (انظر قسم نماذج البيانات).
- قيود فريدة منطقية: وظائف (URL مُطبَّع أو شركة+مسمى+موقع)، شركات (اسم عربي مُطبَّع)، إيميلات (company+email)، جهات (company+linkedin).
- **DB-first**: أي شركة تُجلب من القاعدة أولًا مع ختم `Last Verified` وصلاحية 14 يومًا (FRESH_DAYS).

### 8) كشف التكرار والوظائف المنتهية + حداثة الوظيفة
- Dedupe بمفاتيح مُطبَّعة + أنماط إغلاق (Closed Patterns) + تحقق best-effort.
- شارات حداثة: اليوم / منذ يوم / منذ X أيام / قديمة.

### 9) Kanban بـ 7 مراحل + حقول موسّعة
- المراحل: مُكتشفة → مهتم → تم التقديم → تم التواصل → مقابلة → عرض عمل → مرفوض (مع خريطة توافق للحالات القديمة).
- حقول الطلب: CV المستخدم، المصدر، تاريخ المتابعة، تاريخ المقابلة، هل أُرسل إيميل.

### 10) المتابعة الذكية (Smart Follow-up)
- تنبيه تلقائي بعد 5 أيام من التقديم، ومتابعة ثانية بعد 7 أيام.
- توليد نص المتابعة بالـ AI مع الاستناد لسجل التواصلات السابقة.

### 11) الحملة الذكية (Bulk) الآمنة
- توليد جماعي مخصص (كشف مجال الشركة + تخصيص من الـ CV) مع إلغاء.
- إرسال داخل التطبيق عبر EmailJS بعد **مراجعة واعتماد إجباري** لكل رسالة.
- أثناء الإرسال: **إيقاف مؤقت / استئناف / إلغاء** + شريط تقدم + حالات (مرسل/فشل/تم تخطيه).

### 12) إصدارات CV + توصية + تخصيص
- ملفات CV دائمة متعددة + توصية AI بأفضل CV لكل وظيفة.
- **تخصيص CV بالـ AI لكل وظيفة مع منع صارم للاختلاق** (لا مهارات/خبرات غير موجودة).

### 13) عمليات البحث المحفوظة + التنبيهات
- حفظ معايير البحث، تشغيل "البحث في الكل"، وتنبيهات الوظائف الجديدة (نافذة 24 ساعة) في لوحة التحكم.

### 14) لوحة التحكم
- 10 مؤشرات: وظائف مكتشفة/جديدة، عالية التطابق، شركات، جهات HR، إيميلات صالحة، طلبات، مقابلات، عروض، معدل استجابة.
- 5 رسوم Chart.js: وظائف/يوم (14ي)، طلبات/أسبوع (8أ)، أهم المصادر (doughnut)، قمع التقديم، أكثر الشركات.

### 15) إدارة الـ APIs
- بطاقات لكل خدمة مع اختبار اتصال حي وقياس زمن الاستجابة: Gemini، Serper (إلزامي)، Hunter.io، RapidAPI/JSearch، EmailJS.
- جميع المفاتيح مشفرة **AES-GCM-256** في localStorage.

| الخدمة | الغرض | إلزامية |
|---|---|---|

## 🔐 الأمان — قيد معروف وموثّق

> **قيد بنيوي**: في تطبيق ثابت (Static-only) لا يوجد خادم خلفي، وبالتالي **لا يمكن إخفاء مفاتيح الـ API عن المتصفح بشكل كامل** — أي طلب يصدر من العميل يحمل المفتاح.

**التخفيفات المطبَّقة:**
- تشفير كل المفاتيح بـ **AES-GCM-256** قبل التخزين في localStorage.
- اشتقاق مفتاح التشفير عبر **PBKDF2 (120,000 تكرار)** من بصمة الجهاز (ملح عشوائي محلي + User-Agent) — المفتاح لا يُخزَّن أبدًا بصيغة صريحة.
- حقول المفاتيح من نوع password، ولا تُطبع في أي سجل.

**التوصية**: استخدم مفاتيح بقيود (HTTP referrer / quotas) من لوحات مزوّدي الخدمة، ودوّر المفاتيح دوريًا. للسرية الكاملة يلزم خادم وسيط (Proxy) — خارج نطاق النسخة الثابتة.

## ▶️ التشغيل

1. انشر المشروع كما هو (موقع ثابت) — لا يوجد build.
2. افتح **إدارة الـ APIs** وأدخل مفاتيحك (Serper + Gemini على الأقل) واختبر الاتصال.
3. ارفع CV في **محسّن السيرة الذاتية** ليصبح نشطًا.
4. شغّل **وكيل الصيد الوظيفي** أو **الحملة الذكية**، راجع النتائج، اعتمد، ثم أرسل وتابع في لوحة التحكم.

## 🚧 غير مُنفَّذ / حدود معروفة

- إخفاء مفاتيح الـ API خلف خادم (مستحيل في static-only — موثّق أعلاه).
- فحص حالة الوظيفة (Active/Closed) بشكل قاطع — يتم best-effort بسبب قيود CORS (يُوسم Unknown عند التعذر).
- إرسال EmailJS يتطلب إعداد Service/Template من حساب المستخدم.
- لا توجد مصادقة مستخدمين متعددة — التطبيق شخصي على جهاز واحد.

## 📌 الخطوات التالية الموصى بها

1. Proxy خفيف (Cloudflare Worker) لإخفاء المفاتيح وتوحيد النداءات.
2. مزامنة اختيارية عبر الأجهزة لملفات CV والإعدادات.
3. استيراد/تصدير كامل لقاعدة البيانات (JSON) للنسخ الاحتياطي.
4. إشعارات بريدية للتنبيهات اليومية (عبر EmailJS مجدول).
