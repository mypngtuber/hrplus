# مساعد التوظيف الذكي — AI Career Copilot (مصر 🇪🇬)

تطبيق ويب عربي (RTL) متكامل لرحلة البحث عن عمل في **مصر**: من رفع الـ CV → البحث متعدد المصادر عن وظائف وشركات مصرية → استخراج **إيميلات حقيقية مُتحقَّق منها فقط** → توليد رسائل تقديم **مخصصة لكل شركة** جماعياً → **مراجعة وتعديل** → **إرسال مباشر من داخل التطبيق** → تتبع كل الطلبات.

## الهدف النهائي (المحقق)
نظام متكامل: **CV المستخدم → بحث عن الوظائف والشركات المناسبة في مصر → تحليل الشركة والوظيفة → الإيميل الحقيقي فقط → رسالة مخصصة لكل شركة → مراجعة → إرسال من داخل التطبيق.**

---

## ✅ الميزات المنفذة

### 1. نظام البحث عن الإيميلات (بدون تخمين — نهائياً)
- **أُلغي نظام التخمين بالكامل**: لا أنماط متوقعة ولا اقتراحات مبنية على اسم الشركة.
- المصدر الوحيد: **Hunter.io** — يعرض فقط الإيميلات المؤكد وجودها على نطاق الشركة (ثقة ≥ 50% ولم تفشل في التحقق).
- أولوية تلقائية لإيميلات مناصب HR / Recruiter / Talent Acquisition.
- عند عدم وجود إيميل مؤكد: رسالة صريحة + روابط LinkedIn للتواصل المباشر كبديل آمن.

### 2. نظام كتابة الإيميلات Bulk (الحملة الذكية)
- توليد جماعي لعدد كبير من رسائل التقديم دفعة واحدة مع شريط تقدم.
- الـ AI **يتعرف على مجال عمل كل شركة** ويعرضه كشارة.
- التخصيص بناءً على: مجال الشركة + الوظيفة + خبرات الـ CV + **مطابقة المجال**:
  - خبرة بنفس المجال → تركيز عليها (شارة "خبرة بنفس المجال").
  - بدون خبرة مباشرة → إبراز **المهارات القابلة للنقل** فقط (شارة "مهارات قابلة للنقل") — **ممنوع ادّعاء خبرة غير حقيقية**.
- **مراجعة وتعديل** كل رسالة (العنوان + النص) قبل أي إرسال.

### 3. إرسال الإيميلات من داخل التطبيق
- إرسال مباشر عبر **EmailJS** (من حساب بريدك Gmail/Outlook — 200 رسالة/شهر مجاناً).
- **لا إرسال تلقائي إطلاقاً**: مسودة → اعتماد يدوي → تأكيد → إرسال (مع فاصل زمني آمن بين الرسائل).
- معاينة كاملة + تعديل يدوي + إرسال جماعي للمعتمدة فقط.
- بديل بدون EmailJS: فتح الرسائل في تطبيق البريد (`mailto`) واحدة تلو الأخرى.
- سجل إرسال مباشر (نجاح/فشل لكل رسالة) + إضافة تلقائية للوحة التتبع.

### 4. نظام البحث بالـ CV
- رفع الـ CV **اختياري** تماماً — لكنه يحسّن كل النتائج.
- **حفظ نسخ CV متعددة داخل التطبيق** (جدول `cv_profiles`) + **استرجاعها** + **تفعيل** أي نسخة + تغييرها في أي وقت.
- شريط "الـ CV النشط" يظهر في كل الوحدات مع ملخص المهارات.

### 5. مصادر البحث (LinkedIn + Wuzzuf + Google)
- **JSearch (RapidAPI)**: وظائف مجمّعة من LinkedIn/Indeed/Glassdoor — مفلترة بـ `country=eg`.
- **Google Custom Search**: استعلامات `site:linkedin.com/jobs` و`site:wuzzuf.net` + بحث عام عن شركات توظّف في مصر.
- توسيع ذكي للاستعلامات من الـ CV: يكتشف **مجالات مختلفة** تناسب المهارات القابلة للنقل (لا يقتصر على نفس المجال حرفياً).
- بدون مفاتيح: روابط بحث مباشرة جاهزة (LinkedIn مصر، Wuzzuf، Indeed مصر، Glassdoor، Google).

### 6. التركيز الجغرافي: مصر فقط
- كل عمليات البحث مقيدة بمصر (JSearch `country=eg`، Google `gl=eg`، فلترة كلمات: مصر/القاهرة/الإسكندرية...).
- اختيار مدينة: القاهرة/الجيزة/الإسكندرية/المنصورة/عن بُعد.
- استبعاد النتائج غير المصرية من نتائج Google.

### 7. ربط كل الميزات بالـ CV
- استخراج **ملف مهني** بالـ AI عند حفظ الـ CV: الخبرات، المهارات، الوظائف السابقة، المجالات، المؤهلات، سنوات الخبرة، الكلمات المفتاحية.
- هذا الملف يغذي: توسيع البحث + مطابقة الشركات + تخصيص الرسائل + تحليل الفجوة.
- استرجاع تلقائي للنسخة النشطة عند فتح التطبيق — **بدون إعادة رفع**.

### 8. إدارة واختبار الـ APIs (قسم مخصص)
- بطاقة مستقلة لكل خدمة: **Gemini · JSearch · Google CSE · Hunter.io · EmailJS**.
- لكل خدمة: حقولها + زر **حفظ** + زر **اختبار API** + نتيجة واضحة (زمن استجابة/سبب الفشل/الرصيد المتبقي).
- تعديل/استبدال أي مفتاح من الواجهة فقط — **بدون لمس الكود**.
- جميع المفاتيح مشفرة **AES-GCM 256** (PBKDF2 ×120,000) في المتصفح فقط.

### + الوحدات الأصلية
- **محسّن CV / ATS**: استخراج PDF/DOCX، تحليل درجة التوافق، إعادة صياغة بأفعال قوية، تصدير PDF/DOCX.
- **الفجوة المهارية**: تحليل مقابل السوق المصري + كورسات Coursera/Udemy/YouTube/edX.
- **لوحة التتبع**: Kanban بسحب وإفلات (5 حالات) + جدول + إحصائيات.
- **مكتبة النماذج**: حفظ/تعديل/نسخ/تصدير نسخ CV والرسائل.

## 🔌 الـ APIs المستخدمة (كلها CORS-enabled، بدون خادم وسيط)

| الخدمة | الغرض | إلزامي؟ | مجاني؟ |
|---|---|---|---|
| Google Gemini | كل ميزات الـ AI | ✅ نعم | نعم (AI Studio) |
| JSearch (RapidAPI) | بحث الوظائف | اختياري | خطة مجانية |
| Google Custom Search | LinkedIn/Wuzzuf/Google | اختياري | 100 استعلام/يوم |
| Hunter.io | إيميلات مؤكدة فقط | اختياري | 25 بحث/شهر |
| EmailJS | الإرسال المباشر | اختياري | 200 رسالة/شهر |

## ⚠️ قيود معروفة
- **الإرسال يتطلب EmailJS**: المتصفحات لا تدعم SMTP مباشرة (قيود أمان) — EmailJS يرسل من حسابك عبر API رسمي. البديل: `mailto`.
- **LinkedIn/Wuzzuf يمنعان الـ scraping المباشر** من المتصفح — لذا يتم البحث فيهما عبر Google CSE (الطريقة القانونية المتاحة من جهة العميل).
- PDF الممسوح ضوئياً (Scanned) يحتاج OCR غير متاح حالياً.
- الموديلات التجريبية (3.5/3.6) قد لا تكون متاحة لحسابك — زر "اختبار API" يكشف ذلك فوراً.
